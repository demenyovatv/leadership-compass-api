# Политика конфиденциальности GPT-агента «Компас руководителя»

**Дата обновления:** 14 октября 2026 года.

### 1. Назначение

«Компас руководителя» — GPT-агент для анализа управленческих ситуаций и профессиональной рефлексии руководителей.

### 2. Использование внешнего API

Агент использует Leadership Compass API по адресу https://leadership-compass-api.onrender.com.

При вызове API передаётся код категории управленческой ситуации: `delegation`, `conflict`, `motivation`, `responsibility` или `change`.

API возвращает учебные описания ситуаций, возможные ценностные ориентиры, рекомендации и вопросы для рефлексии.

### 3. Обрабатываемые данные

Разработанный API не требует регистрации пользователей, имён, адресов электронной почты и других персональных данных. API не предназначен для получения полного текста пользовательских сообщений.

Хостинг-провайдер может обрабатывать технические сведения о запросах в соответствии со своей политикой конфиденциальности.

### 4. Хранение данных

Приложение не создаёт собственную базу пользовательских профилей и не сохраняет историю диалогов. Обработка сообщений в ChatGPT регулируется политикой конфиденциальности OpenAI.

### 5. Ограничения использования

Не рекомендуется вводить персональные данные сотрудников, коммерческую тайну и другую конфиденциальную информацию.

Ответы агента предназначены для информационной поддержки и не заменяют индивидуальную профессиональную консультацию.

### 6. Изменения политики

Политика может обновляться при изменении функциональности агента или способов обработки данных.

### 7. Контакт

По вопросам конфиденциальности можно обратиться к разработчику через контактный адрес, указанный в публичном описании проекта.
